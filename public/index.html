01

不靠摘要硬撑的结构化记忆 Structured memory without lossy summaries

对话
只认工具结果和你的原话，模型自己说的只算计划。
目标
待办清单单独存着，记录做到哪一步、还剩什么。
文件
后台记录本地文件有没有变动，平时不放进对话占地方。
Chat
Only tool output and your prompts count as fact. Model text on its own is just a plan.
Goals
The checklist lives outside the chat, tracking where things stand and what's left.
Files
Local file changes are tracked in the background instead of eating up context.

做完一阶段，它可以主动清掉前面的过程继续做。窗口满了需要压缩时，你的原话和待办清单原样保留，不会被重编成走样的摘要。

Once a phase wraps up, Hya can clear out earlier legwork and keep going with a clean window. And when context runs tight, your original prompts and checklist stay word for word instead of getting boiled down into a vague summary.

02

随时叫醒续做的多 Agent 小队 Subagents that hand off, sleep, and pick right back up

派出去的子 Agent 在各自会话里并行工作，不挤占主对话窗口。干完一阶段只交回一份简短交接单就进入休眠，不占额度；后续随时叫醒，带着上次的交接单接着做。

固定流程写成一份文档就能按步骤自动推进，是否达标由外部检查或独立验收判定，不听执行者自评。

Subagents run in parallel inside their own sessions so your main chat stays clean. When one finishes a step, it sends back a short handoff note and goes to sleep at zero token cost. Ping it again later and it wakes right back up from that handoff.

Repeatable workflows live in plain Markdown files and run step by step. External checks or a separate reviewer decide when the job is done, never the worker grading its own work.

03

不绑死窗口的本地常驻工作台 A local workspace that outlives any window

运行 hya，终端和浏览器打开的是同一个界面。关掉窗口任务在后台继续跑，随时重连查看；不满意哪一步，直接把对话和改过的文件一起撤回。

人在外面可以通过端到端加密链接连回自己的电脑，不用把工作搬上第三方云主机，文件、历史和密钥都留在本地。

Run hya and the same interface opens in your terminal and your browser. Close either window and the run keeps going in the background until you check back in. If a step goes sideways, undo rewinds both the chat and the files touched on disk.

When you're away from your desk, connect back to your machine over an end-to-end encrypted link. Nothing moves to a third-party cloud; your files, history, and keys stay on your own hardware.
