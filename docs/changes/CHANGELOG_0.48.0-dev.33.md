# 0.48.0-dev.33

- **Budgeted Bash wait cap, `still_running` yield, and process-group lifecycle supervision.** File-backed budgeted Bash now bounds its foreground wait to `budget / 10` (clamped 15–120 s) and yields `still_running` with its live output artifact and `exit_code` path so slow builds can continue under budget supervision without burning wall time or losing output. Both bare and full Bash (budgeted file, pipe, and PTY modes) export `PYTHONUNBUFFERED=1`, track worker threads via Linux `/proc/<pid>/task/*/stat` and two-pass quiescence (`hidepid=1`-safe), complete promptly when detached (`setsid`) writers retain inherited descriptors, send final group signals while the leader still pins the PGID, and enforce closed-admission drain loops across normal exit and stop signals.
- **Full-mode engine harness retries, empty-turn rescue, wrap-up check, and image decode parity.** The engine harness now aligns its transient retry ladder (8 steps, backoff, `StreamInterrupted` / `PartDeleted` cleanup, and candidate pinning), rescues empty reasoning-only turns without burning turns silently, qualifies `COMPLETION_CHECK` wrap-up prompts using active offered tools, and validates image readability by decoding pixel data in `read_media`.
- **Session-tree JSON streaming (`exec --json --include-subagents`).** Added `hya-store::replay_tree` and `--include-subagents` on headless `exec --json` to stream root and descendant subagent sessions in creation order while recovering live ancestry after transient storage faults.
- **Tool, mail delivery, configuration, and TUI improvements.** Made `todo` `op` parsing forgiving with explicit schema examples, added `effort` hints to `task`, clarified automatic archival on `wait`, added `tools.webfetch.enabled` configuration control, marked `wait` as `ToolResultPolicy::SelfBudgeted` so large nested target arrays survive host capping, prioritized unrecoverable direct mail with cursor-gated pagination and atomic `MailConsumed` commit alongside surviving outer/aliased/nested tool results, unified 600-Unicode-scalar steer preview truncation, and removed deleted parts on `PartDeleted` in `hya-tui`.
- **Kernel and built-in agent guidance updates.** Replaced the over-broad preservation rule in the kernel prompt with targeted end-state verification and refined built-in `hya-main`, `hya-reviewer`, `hya-task`, and task-tool delegation instructions.
