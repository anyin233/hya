# 0.48.0-dev.34

- **Headless narration detection and deadline-aware reasoning controls.** Expanded `exec` unfinished-narration detection to catch imminent-start phrases (including curly apostrophes and specific Chinese action-intent leads) without triggering on completed past-tense summaries. Bounded pre-WrapUp and inter-stage thinking-only streams with an adaptive remaining-time cap (preserving `Stage::Final` writes and deferred `WrapUp` notification), switched cut and rescued-turn notices to a bounded head-and-tail reasoning excerpt while keeping completed empty-turn replay data intact, separated consecutive OpenAI Chat cluster reasoning parts cleanly, and refined `FINAL` guidance to verify untested deliverables before replacing them.
- **Actionable missing-hash `edit` diagnostics.** Missing-hash `[E_BAD_REF]` errors now identify the failing reference, explicitly state that no edits were applied, note in the `edit` schema that shell `sed`/`grep` output lacks anchors, and—after passing workspace-boundary, `Action::Read`, regular-text-file, and 50 KiB checks—append merged `±2`-line live anchors around the requested lines.
- **Resident archive status and per-channel unread counts.** `finalize_resident_archive` now emits terminal `RosterStatus::Done` on `MemberRunStatus::Done` reports (preserving idempotent replay for both `Done` and `Failed`), and `list_channel` counts unread incoming mail per channel log instead of mirroring total inbox unreads onto every channel.
- **Task-scoped workspace boundaries and delegation guidance clarity.** Qualified kernel and subagent scope rules so task-provided credentials remain usable while keeping harness internals and unrelated host/container metadata out of bounds, restored selective delegation alongside explicit `tasks[]` batching against sequential spawn/wait anti-patterns, and trimmed repeated delegation prose.
