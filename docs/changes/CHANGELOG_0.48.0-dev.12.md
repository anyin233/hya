# 0.48.0-dev.12

- **Bare `bash` no longer kills what it started.** `timeout` is now how long a call waits, not how long the command may live. A command still running when the wait ends is left running in the background: the call returns what it printed so far and a `still_running` note with its process group, the file its output keeps going to, the file its exit code is written to, and how to stop it. A command that ends within the wait no longer has its process group killed either, so a job started with `&` keeps running and the `setsid` advice is gone. Only a wait cut short by the run's time budget, and cancellation, still kill the group. Before, the timeout sent SIGKILL to the group: an installation in progress was destroyed and could leave the package database broken, and a job started with `setsid … &` was killed before it could leave the group.
- **Bare mode retries a round after a transient upstream error.** A round that fails with a transient provider error (429, 5xx, a transport error) before the model produced anything is sent again, up to three times after waits of 5, 10 and 20 seconds; not when the run is cancelled, when the wait would reach the final stage of a time budget, or when the attempt had already produced output. Before, one such error ended the run.
- **Completion check window.** With a time budget, the bare completion check is sent while more than two final windows remain (more than 216 s of a 900 s budget, 432 s of 1,800 s), instead of only before the wrap-up stage, which is the last 35% of the budget.
- **Image replay budget 1 MiB.** A request replays at most 1 MiB of tool-result image data, newest first (before: 2 MiB); the images of the newest tool result that has any are still always sent. Measured cost of replayed image data: tens of seconds per megabyte on every later request.
- **Store connection wait.** Opening a session database waits up to five minutes for a connection instead of the library default of 30 seconds, so a run that starts on a busy disk no longer exits with `sqlite: pool timed out`.
