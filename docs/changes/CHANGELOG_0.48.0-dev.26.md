# 0.48.0-dev.26

- **Bare mode: an image file that does not decode is no longer sent to the model.** `read` decodes a PNG, JPEG, GIF or WebP file before attaching it. A file that does not decode gives a text result with its type, size and the decoder's error ("… so it is not attached. The file may be malformed or incomplete."). Before, `read` trusted the file's first bytes; a malformed image made the model service reject the next request with HTTP 400 and the run ended.
- **Bare mode: a round that fails on a transient provider error is retried for about five minutes.** Eight retries after 5, 10, 20, 40, 60, 60, 60 and 60 seconds, where there were three after 5, 10 and 20. A model route can need minutes to stop sending requests to an upstream that throttles or is out of allowance; runs with hours of budget ended 35 to 52 seconds after such a failure began. The conditions are unchanged (a transient error or stream interruption, no part persisted, the wait fits before the final window). Without `--time-budget`, a persistently failing endpoint now ends the run after about five minutes of waiting.
