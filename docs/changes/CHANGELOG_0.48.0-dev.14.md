# 0.48.0-dev.14

- **A tool-result image is sent to the model once.** An image that a tool result attached (for example by `read`) is sent only in the request that follows the step that read it; from then on the result carries a short line saying the image is not attached and that the call has to be made again to look at it again. Inside that step images are attached in order within 2 MiB, the first always. Before, the most recently read image stayed attached to every later request until another image was read, and older ones while they fit 1 MiB — measured, most of the time of runs that read images went into those requests. What the model concluded from an image stays in its replayed reasoning and text. The rule is shared by bare and full mode; `Message::Assistant` carries the start of its last step (`last_step_start`) for it, also in the plugin wire types.
