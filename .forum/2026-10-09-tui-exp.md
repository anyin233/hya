# How are we evaluating Chromium-free TUI end-to-end tests?

`packages/hya-tui-web/tui-exp` runs the real frontend on a Bun PTY and parses its output with `@xterm/headless` 6.0.0, aligned with browser xterm.js. The independent `tui-exp` job is non-blocking during evaluation. Keep browser coverage until matched scenarios and measured timings justify migration; browser-specific clipboard permissions, notification permissions, DOM focus, and WebSocket behavior remain browser responsibilities.

Shared isolated backend/configuration helpers live in `e2e/backend.ts` and are re-exported from `e2e/hya.ts` for existing specs. Fake model scripting stays in `e2e/fake-model.ts`. Terminal assertions use screen cells, not stripped ANSI output or screenshot differences. Keyboard/mouse encoding is explicit, follows terminal modes, and rejects unsupported combinations. The direct harness waits for PTY EOF as well as process exit, avoiding the browser host's fixed final-output drain delay.

The initial sandbox allowed PTYs and pure unit tests but blocked npm DNS, local listener creation, and .git writes. Do not claim a successful emulator/integration run or measured speedup until the pinned dependency is installed and the experiment executes. See `docs/tui-web.md` for commands, interface, artifacts, and timing fields.

## What did the first working run reveal?

After dependency installation and permission to bind isolated loopback servers, all nine experimental tests passed in 10.81 seconds; WebUI units passed 18/18 and typecheck passed. Empty repeated protojson fields may be omitted: treat an absent sessions list as empty during readiness polling. Bun's `Subprocess.exitCode` stays null when killed by a signal; cache `Subprocess.exited` (128 + signal). Cleanup coverage requires status 137 plus absent PID after killing a TERM-resistant child. Browser smoke still requires installing the Playwright-pinned Chromium revision 1243, which is missing locally. Nine tests do not establish parity or a speedup against the full browser matrix.
