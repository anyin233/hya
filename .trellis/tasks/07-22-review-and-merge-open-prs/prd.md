# 检查并合并所有开放 PR

## Goal

审查仓库当前所有开放 PR，并按依赖顺序合并所有通过审查和必需检查的 PR。

## Background

- 当前有两个开放 PR，`#10` 与 `#11` 构成堆叠分支。
- 本地已有未跟踪任务目录与本任务无关，执行过程中不得修改或清理。

## Requirements

- 盘点执行时所有开放 PR，确认目标分支、依赖顺序、检查状态和可合并状态。
- 审查每个 PR 相对其目标分支的完整变更，检查正确性、需求符合性、回归风险和测试覆盖。
- 仅合并无阻塞审查发现、必需检查通过、非草稿且 GitHub 判定可合并的 PR。
- 堆叠 PR 必须按从底层到顶层的顺序处理，并在每次合并后重新确认后续 PR 状态。
- 使用仓库既有合并惯例；不得绕过检查、强制合并或修改无关工作树内容。
- 对不能安全合并的 PR 保持开放，并记录具体阻塞原因。

## Acceptance Criteria

- [ ] 执行时所有开放 PR 均有审查结论和检查状态记录。
- [ ] 所有满足合并条件的 PR 已按依赖顺序合并。
- [ ] 合并后重新查询开放 PR；任何剩余项均有明确阻塞说明。
- [ ] 本地无关未跟踪目录保持不变，任务自身产生的记录可区分。
