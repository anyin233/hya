# 0.48.0-dev.28

- **Bare mode: a round whose model stream fails to open is retried like any other failed round.** An error while opening the stream (HTTP 429 or 5xx after the provider's own attempts, a transport error, no response headers in time) now goes through the same retry rule as a failure in the stream: up to eight retries after 5, 10, 20, 40, 60, 60, 60 and 60 seconds, under the same conditions. Before, the retry applied only once the stream had opened; an error at the open ended the run about a minute after the first refusal. An attempt that never opened writes no step to the log. Full mode is unchanged.
