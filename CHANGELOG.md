# 0.48.0-dev.31

- **Upstream tool-call metadata and served-model cross-model gating.** `Event::ToolCallRequested`, `Part::Tool`, and `PartProjection::Tool` (together with the regenerated Bun and Claude plugin wire contracts) now carry optional upstream `provider_data`, and `projection_to_messages` populates historical `Message::Assistant.model` from `MessageProjection::served_model()`. OpenAI Chat, OpenAI Responses, Anthropic Messages, and Google Gemini encoders replay upstream tool call IDs and reasoning payloads only when `same_model_id` matches the request model, stripping foreign or other-model reasoning and provider call IDs across model switches.
- **Google Gemini thinking alignment (`thinkingLevel`, `thoughtSignature`, multi-step clustering, `GoogleThought`).** Google routes now use `ReasoningReplayPolicy::GoogleThought` and emit `generationConfig.thinkingConfig.thinkingLevel` (plus `includeThoughts: true`) for Gemini 3+ models while keeping `thinkingBudget` + `includeThoughts` for Gemini 2.5 and earlier models. The decoder separates `thought: true` reasoning parts from visible text and captures `thoughtSignature` metadata on thought, text, and function-call parts; the encoder replays `google_thought`, `google_text_signature`, `functionCall.id`/`functionResponse.id`, and `thoughtSignature` across multi-step tool clusters while keeping `systemInstruction` immutable and coalescing mid-conversation `Message::System` entries into `role: "user"`.
- **Anthropic Messages adaptive thinking, prefix binding controls, and transient-notice preservation.** Claude 4.6+ models now encode adaptive thinking (`thinking: {type: "adaptive", display: "summarized"}`, `output_config.effort`, adaptive `max_tokens` floor) while legacy Claude `<= 4.5` and non-Claude routes retain `enabled` + `budget_tokens`. When replaying signed current-turn thinking on adaptive Claude routes, requests attach `thinking.block_binding: {prefix_mismatch_behavior: "drop_block"}` and merge `thinking-binding-controls-2026-08-01` into `anthropic-beta` without duplicates; the decoder concatenates split `signature_delta` chunks and warns on `/input_transformations` thinking drops; and `current_turn_start` skips trailing ephemeral harness notices so signed in-turn thinking blocks remain intact.
- **Kernel dropped-reasoning checks ignore policies that do not re-expand prompts.** `PrevRound` dropped-reasoning detection is now gated by `ReasoningReplayPolicy::expands_next_prompt()`, keeping false-positive notices off `GoogleThought` routes that replay compact `thoughtSignature` tokens without billing prior `thoughtsTokenCount` into subsequent `promptTokenCount`.
