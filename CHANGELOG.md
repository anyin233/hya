# 0.48.0-dev.35

- **Kernel decision hygiene, candidate audit, and web-scope rules.** Strengthened the shared kernel prompt rules (`bare` and full mode) so direct task materials decide over general conventions or priors, existing code or docstrings alone do not prove current behavior is intended when a defect is demonstrated, verified external actions are not reopened outside their documented workflow, and network access stays scoped to documentation, packages, and requested resources or services rather than looking up ready-made solutions or the task's own data files. Added a matching candidate-audit step to the shared `COMPLETION_CHECK` prompt.
- **Bounded error diagnostics on failed provider steps.** Added an optional additive `error` field to `Event::StepFinished` (omitted on normal finishes and backward-compatible with older logs) recording a single-line summary up to 512 characters when a started provider stream fails with `finish: error`, and regenerated the plugin wire contracts.
